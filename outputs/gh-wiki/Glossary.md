# Glossary — واژه‌نامه‌ی پروژه

بازگشت به [[Home]]

| اصطلاح | توضیح |
|---|---|
| **Lead** | مشتری بالقوه (خریدار/مستأجر/مالک) که از یکی از کانال‌ها وارد گفت‌وگو شده |
| **Intent Extraction** | استخراج قصد مشتری (خرید/اجاره، بودجه، محله، فوریت) از متن پیام فارسی محاوره‌ای با AI |
| **Unified Conversation Hub** | لایه‌ی نرم‌افزاری که پیام‌های همه‌ی کانال‌ها (واتساپ، تلگرام، دیوار، ...) را در یک نقطه جمع می‌کند |
| **Wedge** | نقطه‌ی ورود دقیق و پولی به بازار، به‌جای ساخت یک محصول سنگین از ابتدا |
| **GTM (Go-To-Market)** | استراتژی ورود به بازار و رشد |
| **Pilot** | اجرای آزمایشی محصول روی تعداد محدودی مشتری واقعی (اینجا: ۵ دفتر) برای اعتبارسنجی |
| **Conversion** | نرخ تبدیل lead به معامله‌ی بسته‌شده |
| **Command Center** | تصویر کامل و متمرکز از همه‌ی فرصت‌ها/leadها برای مدیر دفتر |
| **Vertical SaaS** | نرم‌افزار اشتراکی طراحی‌شده مخصوص یک صنعت خاص (اینجا: صنف املاک) |
| **Churn / چسبندگی (Retention)** | میزان ماندگاری مشتری در استفاده از محصول؛ چسبندگی بالا یعنی churn پایین |
